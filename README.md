# Cordeau

Appli mobile (iOS et Android) pour suivre le budget, les documents, les plans et la réception des travaux d'une rénovation.

- `CLAUDE.md` — contexte du projet et règles pour coder avec Claude
- `docs/specs-v1.md` — fonctionnalités, données et ordre de développement
- `docs/design-system.md` — design system (couleurs, typo, composants, mouvement)
- `design/tokens.json` — tokens au format W3C Design Tokens (clair et sombre)
- `design/maquettes/` — maquettes de référence des 5 écrans principaux
- `.claude/skills/` — skills de design d'Emil Kowalski (licence MIT, voir `LICENSE-emilkowalski`)
